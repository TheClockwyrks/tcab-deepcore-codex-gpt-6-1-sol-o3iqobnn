# Original Deepcore assets

The pixel artwork was authored here as deterministic drawing operations and rendered with `draw` and `draw-sheet`. The music was composed with `music`; every cue was synthesized with `sfx-synth`. All twelve live effects were authored and exported with `particle-2d`.

`source/` preserves the one-time authoring scripts. These require the authoring tools and are not part of installation or production builds. The PNGs, WAVs and particle JSON files in this directory are the shipped source assets; Vite bundles them without running any generator.

Palette: cold petroleum blue, oxidized brass, warm pressure-suit amber and pale mineral light. Miner frames share one suit, visor, drill and oxygen-pack construction across the eight cycles.
